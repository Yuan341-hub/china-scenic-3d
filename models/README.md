# 模型目录

将 GLB 格式的 3D 模型文件放入本目录，文件名需与 `index.html` 中 `scenicData` 数据的 `model` 字段一致，例如：

- `gugong.glb`（故宫）
- `greatwall.glb`（长城）
- `bingmayong.glb`（兵马俑）
- `dayanta.glb`（大雁塔）
- `xihu.glb`（西湖）
- `lingyinsi.glb`（灵隐寺）
- `zhuozhengyuan.glb`（拙政园）
- `dujiangyan.glb`（都江堰）
- `wuhouci.glb`（武侯祠）

模型缺失时页面会显示发光塔形占位模型，并在右侧信息面板给出提示，不影响其他功能。

模型来源建议：Sketchfab（CC 协议模型，注意署名要求）、或者使用 Blender 自建模型后导出 GLB。
